# Security

## Report a security issue

The Grow project team welcomes security reports and is committed to providing prompt attention to security issues. Security issues should be reported privately via [security@getgrowapp.co](mailto:security@getgrowapp.co). Security issues should not be reported via the public Github Issue tracker.

## Vulnerability coordination

Remediation of security vulnerabilities is prioritized by the project team. The project team coordinates remediation with third-party project stakeholders via [Github Security Advisories](https://help.github.com/en/github/managing-security-vulnerabilities/about-github-security-advisories). Third-party stakeholders may include the reporter of the issue, affected direct or indirect users of World, and maintainers of upstream dependencies if applicable.

Downstream project maintainers and Grow users can request participation in coordination of applicable security issues by sending your contact email address, Github username(s) and any other salient information to [security@getgrowapp.co](mailto:security@getgrowapp.co). Participation in security issue coordination processes is at the discretion of the Grow team.

## Security advisories

The project team is committed to transparency in the security issue disclosure process. The Grow team announces security issues via [project Github Release notes](https://github.com/getgrowapp/smart-contracts/releases).
